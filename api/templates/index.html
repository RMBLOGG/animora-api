🏠 Home
Mendapatkan daftar anime terbaru dari halaman utama.
GET /anime/home Anime terbaru ▼
Response Schema
statusstring"ok" atau "error"
dataarrayList anime terbaru
data[].titlestringJudul anime
data[].slugstringSlug untuk detail endpoint
data[].posterstringURL gambar poster
data[].genresstring[]Daftar genre anime
data[].urlstringURL halaman asli
Contoh Response
JSON
{
  "status": "ok",
  "data": [
    {
      "title": "Devil May Cry (2025) Season 1-2 Batch Subtitle Indonesia",
      "slug": "dmc-2025-batch-subtitle-indonesia",
      "poster": "https://kusonime.com/wp-content/uploads/2025/04/Devil-May-Cry-2025.jpg",
      "genres": ["Action", "Demons", "Fantasy"],
      "url": "https://kusonime.com/dmc-2025-batch-subtitle-indonesia/"
    }
  ]
}

🔍 Search
Mencari anime berdasarkan kata kunci. Mendukung pagination.
GET /anime/search/:query?page=1 Cari anime ▼
Path Parameter
NamaTipeWajibKeterangan
querystringrequiredKata kunci pencarian
Query Parameter
NamaTipeWajibDefaultKeterangan
pageintegeroptional1Nomor halaman
Response Schema
statusstring"ok" atau "error"
dataarrayHasil pencarian (sama dengan home)
pageintegerHalaman saat ini
next_pagestring|nullURL halaman berikutnya, null jika tidak ada
Contoh Response
JSON
{
  "status": "ok",
  "data": [
    {
      "title": "Boruto: Naruto Next Generations 001-293 END Batch Subtitle Indonesia",
      "slug": "boruto-batch-subtitle-indonesia-7",
      "poster": "https://kusonime.com/wp-content/uploads/2017/09/Boruto-Naruto-Next-Generations.jpg",
      "genres": ["Action", "Adventure", "Shounen"],
      "url": "https://kusonime.com/boruto-batch-subtitle-indonesia-7/"
    }
  ],
  "page": 1,
  "next_page": "https://kusonime.com/page/2/?s=naruto"
}

data.posterstringURL poster

data.info.japanesestringJudul bahasa Jepang
data.info.genrestringGenre (comma separated)
data.info.seasonsstringMusim tayang
data.info.typestringTipe (BD, TV, dll)
data.info.statusstringStatus (Completed/Ongoing)
data.info.total_episodestringTotal episode
data.info.scorestringSkor MAL
data.info.durationstringDurasi per episode

data.downloadsarrayLink download per resolusi
data.downloads[].resolutionstring360P / 480P / 720P / 1080P / Subtitle
